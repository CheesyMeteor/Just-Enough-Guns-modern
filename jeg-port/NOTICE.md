# Just Enough Guns: Modern

An unofficial NeoForge 1.21.1 port and fork of [Just Enough Guns](https://www.curseforge.com/minecraft/mc-mods/just-enough-guns)
by MigaMi (source: https://github.com/MigaMiDev/Just-Enough-Guns), which is itself a fork of MrCrayfish's Gun Mod.
All original code, design and assets belong to their authors.

This project is licensed under the GNU General Public License version 3 (see `LICENSE.txt`), the same licence the
original project lists. Files modified from the original were changed as part of the port to NeoForge 1.21.1 and
for the additions below.

## Changes from the original
- Magazine system (server toggle `magazineFeedEnabled`), magazines, Magazine Loader and Powered Magazine Loader.
- Gun repair by crafting with a repair kit; no attachment durability (Explosive Muzzle excepted).
- `gunnerSpawnsOutsideRaids` toggle.
- NeoForge 1.21.1 port.

The magazine system is inspired by Just Enough Guns New (https://github.com/maoruiQa/just-enough-guns-neoforge).
Some model files keep the credit lines of their original authors.
